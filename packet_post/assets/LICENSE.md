# Packet Post font

The bundled font8x8 basic Latin glyphs are public domain, as declared in
the preserved source header. Author: Daniel Hepper; based on Marcel
Sondaar and IBM public-domain VGA glyphs.

Source: [font8x8_basic.h](https://github.com/dhepper/font8x8/blob/master/font8x8_basic.h).
Retrieved September 18, 2026. No network request occurs at runtime.

The original header is preserved as `font8x8_basic.h`. `font.png` is a
16-column, 8-row RGBA atlas derived from those 128 eight-by-eight bitmaps,
with one transparent row above and below each glyph.
